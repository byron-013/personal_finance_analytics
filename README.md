# Personal Finance Analytics

Personal finance transaction analysis system with SQL-driven insights. Built to analyze spending patterns, track budgets, and generate actionable financial recommendations.

## Tech Stack

- **Python** — Data generation, analytics, and visualization
- **SQLite** — Normalized relational database
- **Pandas** — Data manipulation and analysis
- **Matplotlib / Seaborn / Plotly** — Charting and interactive dashboards
- **Faker** — Realistic synthetic data generation
